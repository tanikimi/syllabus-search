# Syllabus Search

和歌山大学の非公式シラバス検索サイト

[https://syllabus-search.kiminori.me/](https://syllabus-search.kiminori.me/)


## 概要

授業名、およびフィルターを組み合わせて、授業情報（シラバス）を検索することができます。

対応しているフィルターは以下の通りです。

- 所属
- 開講期間
- 学年
- 曜日
- 時限
- オンライン
- 担当教員

また、授業名はスペース区切りでのAND検索が可能です。
